# Bundled Vietnamese fonts

Noto Sans and Noto Serif by The Noto Project Authors, licensed under SIL Open Font License 1.1; see OFL.txt. Downloaded from the official Google Fonts repository on 2026-11-03:

- https://github.com/google/fonts/tree/main/ofl/notosans
- https://github.com/google/fonts/tree/main/ofl/notoserif

Static WOFF2 instances at normal width, subset to Latin/Latin Extended, Vietnamese (including combining accents), punctuation, currency, arrows, and current UI characters. Text is served as UTF-8. No external font service or installed Noto font is required. FontTools 4.60.1 generated these instances; upstream SHA256 values and coverage checks are in manifest.json.

Next.js next/font/local publishes content-hashed files with display: swap. System fallbacks cover downloads disabled by browser settings.
